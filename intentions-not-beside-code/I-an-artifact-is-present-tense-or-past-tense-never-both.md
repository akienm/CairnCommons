# I-an-artifact-is-present-tense-or-past-tense-never-both — every artifact is one tense

Every artifact in the corpus is exactly one tense, and nothing is both.

**Present-tense** artifacts are what a mind loads by default: charters
(`intention+why.json`), CLAUDE.md, MAP.md, state files, code and its comments.
At each design shift a present-tense artifact is **rewritten whole** so it reads
as written today. Provenance shrinks to a pointer — a ticket id, a ruling id —
never a narrative paragraph. Git keeps every prior version, so the rewrite
loses nothing; the narrative the rewrite displaces freezes into history in the
same act. Code comments are inside this set: a headstone comment is a stale
claim living in an artifact that reads as current.

**Past-tense** artifacts are the records of truth: `history`, slates, voyages,
decisions, ideas. Law 7 holds untouched — append-only, permanent, an in-place
edit is the defect. What changes is their *reach*: a past-tense store is opened
deliberately, as archaeology, and is never loaded by default — **except through
a compiled current-truth face**. The two in-house faces that legalize the
clause: a charter's `state`, a pure function of its `history`; and the
SessionStart slate injection, which loads the latest slate and only the latest.
The generalization covers every mind's default context, CC's own memory
included: a store loaded by default holds current truth only; append-only
stores exist, and are opened, not loaded.

**Why.** A model reader weights whatever sits in context as present tense, so
an outdated history bit reads as true — history creates noise. The corpus's own
house style fed the leak by writing history *into* the present-tense artifacts:
status-stamps of retirement, date-stamped parentheticals narrating a change,
clauses recounting what a thing used to be. This is Law 9 turned on the
corpus's prose — an older paragraph is not evidence about the current design —
and Law 1: a stale claim read as current spends the resolver re-litigating the
settled.

**Corollaries.**

- **Summarizing rides PROVED.** There is no periodic summarizing pass — a clock
  re-reading everything is the poll this corpus refuses. The event already
  fires: the PROVED crossing's charter delta *is* the summarizing pass. It
  rewrites the charter to present tense while the voyage narrative freezes into
  history, one act, two tenses each landing where they belong.
- **A migration is atomic** — one voyage, no partway — unless a cast ticket's
  cursor owns the partway. The defect in a slow migration is not partway-ness;
  it is partway with no single owner of the fact. Two spellings coexisting with
  no ticket is the thing forbidden.

**Enforcement** is carried by this piece's three children, each its own voyage:
`a-dated-append-in-a-charter-is-a-red` (the shape-check that reds a dated
append inside a present-tense artifact — that ticket owns the pattern list),
`the-briefing-surface-is-charter-plus-state-never-history` (the default reading
path structurally excludes history), and `the-present-tense-corpus-rewrites-once`
(the one-time sweep that rewrites the standing specimens).
